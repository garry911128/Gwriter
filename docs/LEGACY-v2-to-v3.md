# GWriter v2 → v3 需求處置對照

本文件防止重作時把舊版 Web 架構誤當成新版產品需求。舊 `SRS.md` 保留為 v2 現況與遷移證據；新版產品權威為 `docs/SRS-v3-rebuild.md`。

## 保留並重新設計

| v2 領域 | v3 處置 |
|---|---|
| 小說、章節管理 | 保留；加入選用卷、垃圾桶、版本化結構正文 |
| 人物與世界設定 | 擴大為統一卡牌、範本、自訂欄位及關係圖 |
| 草稿快照 | 改為復原日誌、自動存檔與不可變版本歷史 |
| AI 助手 | 保留；限本機 Ollama、明確上下文、建議先審核 |
| 大綱 | 擴大為結構大綱、劇情線／伏筆及故事時間線 |
| 字數統計 | 擴大為手寫、AI、貼上、還原來源分流 |
| 富文字編輯 | 保留能力；淘汰 HTML 權威格式，改為版本化 JSON |
| 資料隔離 | 改由作業系統帳號及工作區目錄提供 |
| 資料庫 migration | 保留原則；MySQL migration 改為 SQLite migration |

## 淘汰

| v2 需求 | 淘汰理由 |
|---|---|
| 註冊、登入、登出、JWT、密碼、電子郵件 | 單機無帳號產品不需要應用程式身分系統 |
| REST API、CORS、Bearer token、request ID | 正式產品不再是瀏覽器對遠端後端架構 |
| MySQL、三容器 Compose、Nginx | 正式版改為桌面 App 與內嵌 SQLite；Docker 只供開發 |
| 多作者資源歸屬及 404 隱匿 | 單工作區不存在跨作者存取 |
| `draft/published` | 無公開發布語意，改用五段創作狀態 |
| 外連封面作為唯一圖片方案 | 改為受管理的本機資產；外連僅可作選用來源 |
| 固定三欄 Bootstrap Web 版面 | 改為可收合、可調整的桌面工作區 |
| 公開平台、讀者端、社群、金流藍圖 | 與隱私優先作者工作台定位不符 |

## 必須遷移的舊資料

- `novels` → 作品；狀態映射需預覽。
- `chapters` → 章節；HTML 轉版本化結構 JSON。
- `characters` → 人物卡；既有欄位映射至系統人物範本。
- `world_items` → 對應類型的卡牌；未知分類保留為自訂類型或標籤。
- `drafts` → 章節版本；原始 HTML 留在遷移證據包。
- 封面與頭像 URL → 外部資產參照；匯入時不在背景下載。

## 不可沿用的錯誤假設

- 「場景卡存在」不代表正文必須拆成場景。
- 「AI 可分析」不代表可以背景掃描作品。
- 「本機」不代表資料庫已加密。
- 「備份」不等於 DOCX／EPUB 等交稿匯出。
- 「作者改名」不代表正文應自動全域取代。
- 「卡牌關係圖」不代表圖的視覺位置就是領域關係本身。
